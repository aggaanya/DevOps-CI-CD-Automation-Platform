# Phase 5 — Security & Reliability Gap Matrix

> Derived from the Step 1 audit (three parallel codebase audits + direct file validation).
> Severity: CRITICAL / HIGH / MEDIUM / LOW / ACK (acknowledged, no change) / DEFERRED (out of Phase 5 scope).

| 1 | Webhook auth (GitLab) | When `webhook.gitlab.secret` is blank, `verifyGitlabToken` returns `true` — **fail-open**. Any unauthenticated request is accepted.
